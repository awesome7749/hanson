# 询价前先做功课：如何用好 Mass Save 家庭能源评估

**Draft — unpublished · 中文 · reviewed October 2, 2026**

一份轻松的准备清单，帮您把能源评估报告变成实用的住宅改造计划。

考虑安装热泵时，先了解房子的实际情况。Mass Save 家庭能源评估有助于发现节能改造机会；热泵安装报价则说明设备和施工安排。把两部分信息放在一起，下一步会更清楚。

## 快速摘要

- 先确认您家是否符合项目参与条件。
- 提前整理舒适度问题和想问的事情。
- 把评估报告提供给安装商。

## 先了解这次评估的用途

Mass Save 将家庭能源评估介绍为节能机会检查，并提供包含建议和可用优惠的能源报告。请通过项目官方渠道确认您家地址的资格及预约安排。

借这次机会聊聊整栋房子：住着不舒服的房间、平时很少查看的阁楼，以及计划更换的设备，都值得提出。

Source: [Mass Save: Homeowners Get Started](https://www.masssave.com/get-started/homeowners)

## 花五分钟整理房屋情况

记下哪里有漏风、冬天不爱待在哪个房间，以及夏天最想改善什么。如果知道现有供暖设备的年龄，也一起记录。不必把房子的历史查得一清二楚。

准备好以前的评估报告、近期能源账单和装修计划。我们的建议是先选出三个最重要的问题，避免聊着聊着忘了。

## 把报告变成有顺序的计划

评估后，问清哪些建议适合先做，哪些需要其他专业人员进一步检查。把报告保存好，后续询价时还会用到。拿到报告只是计划的开始。

如果准备增加保温或做空气密封，请告诉暖通安装商。询问这些改造是否会影响供暖设计，以及什么时候适合确定最终设备。

## 让房屋信息进入设备讨论

Hanson Home 建议您在询价时分享评估报告，并请安装商说明服务哪些房间、设备放在哪里，以及还有哪些施工问题待解决。

列一个小清单：下一步联系谁、对方需要什么资料、接下来要做什么决定。目标是在预约施工前，先把整个计划看明白。

## 与 Hanson Home 聊聊您的计划

欢迎把评估报告带给 Hanson Home。我们可以结合您的舒适度目标，讨论热泵方案和安装前需要确认的问题。
